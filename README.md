# Task Manager

Aplicación CRUD de gestión de tareas construida con Flask y SQLite.
Proyecto desarrollado para la Tarea 3 (Programación III - Git y Git Flow).

## Instalación
pip install -r requirements.txt
python app.py

## Ramas
- main: producción
- dev: integración
- qa: pruebas
- feature/*: funcionalidades
- hotfix/*: correcciones urgentes
